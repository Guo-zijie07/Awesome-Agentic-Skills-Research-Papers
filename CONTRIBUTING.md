# Contributing

Thanks for helping keep this list useful.

## Inclusion Criteria

A paper should usually satisfy at least one of these:

- It defines, learns, retrieves, composes, evaluates, optimizes, or governs reusable agent skills.
- It studies skill libraries, skill routing, skill distillation, executable procedural knowledge, or progressive disclosure.
- It is a precursor that clearly shaped later skill-based agents, such as tool learning, experiential learning, or executable code skill libraries.
- It provides a survey, benchmark, dataset, or security analysis directly relevant to skill-equipped agents.

Avoid adding broad LLM-agent papers unless the connection to reusable skills is explicit.

## Entry Format

Use this table format in `README.md`:

```markdown
| Year | Paper | Links | Why it matters |
| --- | --- | --- | --- |
| 2026 | Paper Title | [arXiv](https://arxiv.org/abs/xxxx.xxxxx) | One clear sentence. |
```

Prefer primary links in this order:

1. arXiv, ACL Anthology, OpenReview, publisher page, or official paper page.
2. Official project page or official repository.
3. Secondary summaries only when the primary source is not available.

## Notes

- Keep descriptions short and factual.
- If a paper is under review or a technical report, say so only if relevant.
- Do not add implementation-only skill packages to the paper list; add them to related resources only when they are used as research artifacts.
